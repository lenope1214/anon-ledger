# 📒 거래장부 (anon-ledger)

컴장부를 대신하는 간단한 거래 장부 웹앱입니다.
**PC와 휴대폰 모두** 브라우저로 같은 장부를 사용할 수 있으며,
Vercel에 배포하면 어디서든 24시간 접속됩니다.

## 주소

- **운영**: https://ledger.anon-chat.kr — `production` 브랜치가 머지될 때마다 자동 배포
- **개발 확인용**: https://dev-ledger.anon-chat.kr — `develop` 브랜치의 최신 상태 (Vercel 도메인에서 브랜치 지정)

## 기능

1. **상호관리** — 거래처(상호) 등록·수정·삭제, 검색, 상호별 미수금 확인
2. **제품관리** — 상호별 제품(품명·규격·단위·단가) 관리
3. **거래관리** — 거래 입력(품목 여러 개, 부가세 별도/포함/없음 자동 계산, 입금액·잔액),
   **거래명세표** 인쇄 및 PDF 저장
4. **내 정보** — 거래명세표의 '공급자' 칸에 들어갈 내 사업자 정보 설정, 비밀번호 변경, 백업 다운로드
5. **로그인** — 비밀번호로 장부 보호 (외부 공개 시 필수)

## 실행 방법

별도 프로그램 설치 없이 [Node.js](https://nodejs.org/ko) (LTS 버전)만 설치하면 됩니다.
`npm install` 도 필요 없습니다.

```bash
node server.js
```

실행하면 접속 주소가 출력됩니다.

- **PC에서**: 브라우저로 `http://localhost:3000` 접속
- **휴대폰에서**: 휴대폰을 PC와 **같은 와이파이(공유기)** 에 연결한 뒤,
  실행 시 출력된 `http://192.168.x.x:3000` 주소로 접속

> 💡 휴대폰에서 접속이 안 되면 Windows 방화벽에서 Node.js의
> '개인 네트워크' 접근을 허용해 주세요. (처음 실행 시 뜨는 방화벽 창에서 [허용])

포트를 바꾸려면: `PORT=8080 node server.js` (Windows CMD: `set PORT=8080 && node server.js`)

## 계정 (회원가입 / 승인 / 로그인)

- **여러 사람이 각자 계정을 만들어 쓸 수 있습니다.** 계정마다 완전히 분리된
  자기 장부(상호·제품·거래·설정)를 갖습니다.
- 이용 흐름: **회원가입 → 관리자 승인 대기 → 승인 → 서비스 이용**
  - 가입 직후에는 '승인 대기' 화면이 보이고, 관리자가 승인하면 바로 이용할 수 있습니다.
- **가장 먼저 가입한 계정이 관리자**가 됩니다 (자동 승인). 배포 직후 본인이 먼저 가입하세요!
  - 관리자는 [👑 관리자] 탭에서 가입 신청을 승인/거절하고, 계정을 삭제할 수 있습니다.
- 아이디는 2~20자 한글·영문·숫자, 비밀번호는 4자 이상.
- 로그인 상태는 90일 유지되고 **사용할 때마다 자동 연장**되므로, 계속 쓰는 기기에서는
  다시 로그인할 일이 없습니다. (90일 내내 접속하지 않은 기기만 만료)
- 비밀번호는 원문이 아닌 **scrypt 해시**로 저장됩니다.
- 예전 단일 비밀번호 버전을 쓰던 경우: 업데이트 후 **첫 번째로 가입하는 계정(관리자)**이
  기존 장부 데이터를 그대로 물려받습니다.
- 사용자가 비밀번호를 잊어버렸다면: 관리자가 그 계정을 삭제한 뒤 다시 가입 →
  재승인하면 됩니다. (장부 데이터도 함께 사라지니 미리 백업을 받아 두는 습관을 권장)

## 데이터 저장과 백업

- 데이터는 서버 한 곳에만 저장됩니다 — 로컬 실행 시 `data/db.json` 파일,
  Vercel 배포 시 Neon(Postgres) 데이터베이스. PC·휴대폰 브라우저에는 데이터가
  남지 않으므로, 어느 기기에서 로그인하든 항상 같은 장부입니다.
- **백업**: [내 정보] 탭의 '백업 파일 다운로드' 버튼으로 내 계정의 장부를 JSON 파일로 받아 보관하세요.
- **복원**: [내 정보] 탭의 '백업 파일로 복원'에 백업 파일을 올리면 내 장부 전체가
  그 내용으로 교체됩니다 (계정·비밀번호는 유지). 로컬↔Vercel 간 데이터 이동도 이 방법으로 합니다.

## Vercel로 배포하기 (외부 접속, 추천)

PC를 켜 두지 않아도 어디서든 접속되는 방법입니다. 무료 요금제로 충분합니다.

1. [vercel.com](https://vercel.com)에 GitHub 계정으로 가입 → **Add New → Project** →
   이 저장소(`anon-ledger`)를 Import (설정은 기본값 그대로 Deploy)
2. 프로젝트 **Settings → Git → Production Branch**를 `production`으로 변경
3. **Storage 탭 → Create Database → Neon (Postgres)** 생성·연결
   (환경변수 `DATABASE_URL`이 자동 등록됩니다)
4. **Deployments → 최신 항목 → Redeploy** (DB 연결을 반영하기 위해 한 번 재배포)
5. 발급된 `https://프로젝트명.vercel.app` 주소로 접속 → 첫 화면에서 비밀번호 만들기 → 끝!

- **기존 PC 데이터 옮기기**: 로컬 서버의 [내 정보] → 백업 파일 다운로드 →
  Vercel 주소의 [내 정보] → '백업 파일로 복원' 업로드. 이게 전부입니다.
- Vercel에서는 데이터가 Neon(Postgres)에 저장됩니다. 무료 DB는 한동안 사용이 없으면
  절전 상태가 되어 첫 접속이 1~2초 느릴 수 있습니다 (데이터는 그대로 유지).

## 그 외 외부 접속 방법 (PC를 서버로 쓸 때)

- **Cloudflare Tunnel (무료)** — `cloudflared tunnel --url http://localhost:3000` 실행으로
  `https://` 주소 발급. 데이터가 내 PC의 `data/db.json`에 남습니다.
- **Tailscale (무료)** — PC·휴대폰에 앱 설치 후 같은 계정 로그인. 외부에 전혀 공개되지 않는 VPN 방식.

## 참고

- 로컬 실행 시 서버는 Node.js 기본 모듈만 사용합니다 (`npm install` 불필요).
- Vercel 배포 시에만 `@neondatabase/serverless` 패키지가 사용됩니다 (Vercel이 자동 설치).
